# Case studies

Five products I built solo in 2026 by directing Claude Code agents. Each page covers the problem, what I built, the architecture, verified numbers, the hardest engineering problem, and how the agents' work was checked.

| Product | What | Live | Headline number |
|---|---|---|---|
| [CarrierTruth](carriertruth.md) | US trucking carrier registry with a daily change history | [carriertruth.com](https://carriertruth.com) | 4,484,464 carriers, 107,026 change events |
| [AccessAtlas](accessatlas.md) | Accessibility auditor directory plus a headless-browser site scanner | [verscala.com](https://verscala.com) | 574 agencies, 19 countries, 794 tests |
| [DetNav](detnav.md) | Multilingual information for families of people held in US immigration detention | [detnav.com](https://detnav.com) | ~1,089 pages in 4 languages |
| [homeequitymath](homeequitymath.md) | Home-equity calculators with dated, re-verified lender rates | [homeequitymath.com](https://homeequitymath.com) | 19 calculators, 20 lender rates, 245 tests |
| [IV Index](ivindex.md) | Mobile IV therapy directory where every price has a source | pre-launch | 192 providers, 46 tests + 5 build gates |
